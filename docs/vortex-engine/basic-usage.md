# Basic Usage
All Vortex Devices follow the same principles for Navigation, Menus and Key Terminology.

## Navigating 
There is mainly _three_ ways to navigate on a device: **short** click, **long** clicks, and **holds**.

  1. **Short clicks** often cycle through options  
  2. **Long clicks** typically select the current option
  3. **Holds** are rare, primarily for opening the menus 

Almost everything can be achieved with only **short** and **long** clicks.

## Menus

Each device has _menus_ which allow the device to be programmed, or controlled. 

The _menus_ on all Vortex Devices work the same, the nagivation controls described above are used to interact with menus.
